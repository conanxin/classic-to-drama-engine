# P7C Test Protocol

status: `READY_FOR_EXTERNAL_PARTICIPANTS`

## Session outline

1. **Notice and consent — 2 minutes.** Explain local-only recording, anonymous code and right to stop.
2. **Part A, onboarding — 6–8 minutes.** EP01 in the assigned Script or Graphic condition, followed by three recall/comprehension items.
3. **Part B, identity — 6–8 minutes.** EP19 in the counterbalanced mode, followed by three identity/knowledge items.
4. **Part C, action — 6–8 minutes.** EP27 Graphic Mode, followed by three action/prop items.
5. **Short ratings and open response — 3–5 minutes.** Export the local JSON result.

## Counterbalancing

Alternate assignment by arrival order: A, B, A, B. Do not let the same participant read both versions of the same episode. EP27 stays Graphic for both groups because it is a product stress test, not a between-mode comparison.

## Facilitation rule

The facilitator may restate the task and point out that assistance exists, but may not explain a relationship, identify a character, reveal an answer, or teach the interface before the participant attempts it. If help is needed, record the moment in notes.

## Completion and stopping

A participant may stop at any time. Mark the session stopped and export if they agree. Partial sessions remain visible as partial; they are never converted to completed data.

## Data handling

The test route stores state in browser localStorage and downloads a JSON file only after an explicit Export action. It does not upload, identify, email or fingerprint the participant. The user may later place exported files in a task-owned analysis folder and run the offline analyzer.
