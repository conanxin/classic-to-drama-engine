# Content model

- **Episode**: exact V2 title, metadata, five scenes, ordered action/character/dialogue blocks, source books, cast, locations and animatic runtime.
- **Character**: four principal identities plus supporting cast frequency, frozen voice/arc references and P4 state matrices.
- **World**: reader-facing story families derived from P3 scene locations.
- **Visual**: approved P4 principal sheets, standing-set anchors, selected hero frames and thirty color keys.
- **Storyboard**: 173 board pages and thirty contact sheets; every page is labelled technical.
- **Document**: an item explicitly listed in `content/PUBLICATION_MANIFEST.json`.
- **Media**: an approved asset with source path, published path, byte length and SHA-256 in `content/ASSET_PUBLICATION_MANIFEST.json`.

V2 Markdown remains the screenplay authority; the web layer applies presentation transforms only.
