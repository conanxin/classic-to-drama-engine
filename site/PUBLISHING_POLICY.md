# Publishing policy

Publication is allowlist-only. The build never recursively exposes repository content.

Allowed: complete V2 screenplay text, curated reader-facing project documents, P4 approved visual assets, technical storyboard PNGs/contact sheets, P4/P5 previs, and compressed P5 episode animatics.

Forbidden: rejected visual targets, runtime internals, authorization registries, temporary evidence, failed sandbox logs, credentials, machine usernames, absolute local paths and intermediate renders. Technical boards remain labelled `TECHNICAL STORYBOARD`; previs remains labelled `PREVIS`.

All P6 research, outreach, booking, financing and payments remain outside this publication phase.
