# Facilitator Guide

## Before the session

- Open `/graphic/test/` on the intended device.
- Alternate condition A/B; do not choose based on participant ability.
- Ask only the familiarity category, not demographic details.
- Confirm that the participant understands local-only storage and voluntary export.

## During reading

Observe without teaching. Note where the participant hesitates, scrolls backward, opens “现在有哪些人？”, opens a character assist, expands source text, switches mode, or tries to use a control that does not work. Do not answer story questions.

Neutral prompts are limited to: “请按你平常的方式继续”, “可以使用页面上任何你看到的辅助”, and “你可以随时停止”.

## After each episode

Have the participant return to the test route before answering. Do not correct answers. If the participant wants to explain uncertainty, capture it in the open response after the objective questions.

## Closeout

Ask the participant to export only after completion. Store the file under an anonymous code, never a real name. Do not combine facilitator notes containing identity with the exported JSON. Run the offline analyzer only on a task-owned local directory.
