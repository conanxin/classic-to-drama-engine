# Graphic and Symbol Language

Status: `FROZEN_P4_GRAPHIC_LANGUAGE`

The production avoids invented fantasy runes. Marks arise from use: vessel codes burned into inventory boards, property tick marks, axe-base numbers, knot sequences, tree counts, key profiles and loom ledger notation. Their shapes are blunt, cuttable and repeatable by an art department.

- Household: vertical tally + open threshold notch.
- Ship: vessel code + station/oar notch, never shared across fleets.
- Contest: AX01–AX12 stamped under each base; visible only in property/reference images.
- Blood/wet/damage overlays: `B0–B5`, `W0–W4`, `D0–D6` appear on slates/manifests, never as diegetic labels.
- Divinity: no sigil overlay. Athena's owl pin remains a physical clasp; Poseidon has no logo.
- Recognition objects carry makers' evidence, not explanatory inscriptions.

All on-screen writing or marks must be plausible within the material/process that made them. Modern typography exists only in P4 boards and manifests.
