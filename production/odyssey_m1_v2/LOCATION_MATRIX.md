## Reuse locks

- S1 geometry is never casually changed: the EP26–28 action map depends on the same doors and columns seen before violence.
- S2 redresses preserve unique floor and portal signatures so Pylos, Sparta, Phaeacia, Aeolus, and Circe do not read as the same institution.
- S5 changes horizon side, rock profile, surface wetness, vegetation, foreground object, and sound motif together; color grade alone is insufficient.
- U09 can reuse S5 rocks only after complete silhouette and floor replacement; Underworld cannot look like a night beach.
- U10 is protected for the finale; earlier orchard imagery is insert-only so the land recognition has production value.
