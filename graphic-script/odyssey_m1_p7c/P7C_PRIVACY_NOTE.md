# P7C Privacy Note

The P7C harness is privacy-first and static. It uses no account, database, analytics service, cookies, advertising tracker or automatic upload.

Recorded locally: anonymous code, broad device class, assigned condition, session/task timing offsets, route/mode/scene events, help openings, answers and completion state.

Not recorded: real name, email, IP address, precise location, browser fingerprint, contact information, credentials or browsing history.

A participant may stop at any time and may clear the current local session from the Test Mode page. A result leaves the browser only when the participant deliberately downloads JSON and chooses to share that file. Synthetic fixtures are marked `synthetic_fixture: true` and the analyzer excludes them from real-participant aggregates.
